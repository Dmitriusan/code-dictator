## Customize Code Dictator

- **Preferred Languages** — Set a shortlist for quick language switching
- **Recording Mode** — Toggle (press twice) or Hold-to-talk
- **Audio Isolation** — Noise reduction for noisy environments
- **Code-Aware Mode** — "open paren" → `(`, "semicolon" → `;`
- **Default Target** — Auto-detect, editor only, or clipboard only
