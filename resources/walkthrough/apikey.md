## Set Your API Key

Your API key is stored securely in your operating system's keychain via VS Code's SecretStorage.

- **ElevenLabs**: Get your key at [elevenlabs.io/app/settings/api-keys](https://elevenlabs.io/app/settings/api-keys?via=code-dictator)
- **OpenAI**: Get your key at [platform.openai.com/api-keys](https://platform.openai.com/api-keys)
